# Task

Revise only the specified storyboard section, using the teacher's comment.

# Constraints

- Preserve the learning goal, the level, the method, the transitions to neighbouring sections, and the
  mathematical correctness.
- Keep the narration matched to the section's duration: about 13 characters, or 2.1 words, per second.
- If the comment changes the length considerably, adjust `duration_seconds` to match and stay between 6 and
  35 seconds.
- Keep the section's visual shape: a diagram section keeps short labels of at most 16 characters, and a
  statement section keeps at most four short lines.

# Output format

Return only the complete replacement section.
